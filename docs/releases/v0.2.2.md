# Spotify Booster 0.2.2 — Interface et mises à jour GitHub

## Installation Windows x64

Téléchargez **SpotifyBooster-Setup-x64.exe**, fermez Spotify Booster puis lancez
l’installateur. Il ne demande pas de droits administrateur. Les préférences de
la version installée sont conservées. Le runtime .NET est inclus.

Cette première version équipée de l’updater doit être installée manuellement.
Pour les versions suivantes : **Réglages → Vérifier les mises à jour → Installer**.
Le téléchargement contrôle la taille et le SHA-256 de l’asset GitHub, puis lance
l’assistant d’installation après fermeture de Booster.

L’archive **SpotifyBooster-Portable-x64.zip** est facultative. Extraire tout son
contenu ; conserver le dossier Data pour une mise à jour portable manuelle.

## Nouveautés

- Interface noire/verte avec navigation latérale et disposition compacte.
- Cadran de gain animé, lié au traitement audio existant.
- Canal stable GitHub, vérification manuelle et installateur intégré.
- Validation des téléchargements et erreurs explicites si GitHub est indisponible.

## Limites importantes

- Application et installateur non signés : Windows peut afficher un avertissement.
- Le hash vérifie l’intégrité, pas une signature indépendante de l’éditeur.
- Pas de rollback automatique ; le remplacement portable reste manuel.
- Le routage audio nécessite toujours un périphérique virtuel installé séparément.
- Aucune installation automatique de pilote. Le backend commercial n’est pas livré.
- L’amplification élevée peut endommager l’audition ; commencer au gain neutre.
- La mise à jour complète depuis une ancienne installation reste à valider sur un PC de test.

Les résultats de build et tests du paquet sont joints dans release-report.txt.
